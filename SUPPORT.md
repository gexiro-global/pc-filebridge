# Support

Use [GitHub Issues](https://github.com/gexiro-global/pc-filebridge/issues) for reproducible installation problems, documentation defects, and feature requests that preserve the create-only security model.

Before opening an issue:

1. Use the latest release and Node.js 22 or newer.
2. Run `npm run check` from a clean checkout.
3. Remove credentials, private filenames, absolute host paths, tunnel identifiers, configuration contents, and document contents from logs.
4. Include the operating system, Node.js version, release tag, failing command, structured FileBridge error code, and a synthetic reproduction.

Do not report vulnerabilities in a public issue. Use [GitHub private vulnerability reporting](https://github.com/gexiro-global/pc-filebridge/security/advisories/new) as described in [SECURITY.md](SECURITY.md).

Support is best-effort and does not include recovery of deleted or overwritten data because PC FileBridge deliberately exposes no such operations.
